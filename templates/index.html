ACTIVE SECURITY ARCHITECTURE

Built on Verifiable Hybrid Cryptography

Every checkout transaction is encrypted, wrapped, digitally signed, and replay-checked using industry-standard cryptographic primitives.

AES-256-GCM Encrypted Transactions

Each order generates a fresh 256-bit key and unique 96-bit nonce with a 128-bit authentication tag to detect any payload tampering.

RSA-OAEP Secure Key Exchange

Ephemeral AES-256 session keys are wrapped using the server's 3072-bit RSA public key with OAEP SHA-256 and MGF1-SHA256 padding.

RSA-PSS Digital Signatures

Canonical transaction metadata and ciphertext are signed with 3072-bit RSA-PSS (SHA-256) and verified against the user's registered public key.

TLS 1.3 Secure Communication

Strict TLS 1.3 transport encryption with X.509 certificate chain verification and hostname validation protects data in transit.

CSRF Protection

Synchronizer CSRF tokens, SameSite=Lax HttpOnly session cookies, and open-redirect guards protect every authenticated state change.

Role-Based Access Control

Granular authorization separates Guest, Customer, and Admin operations, backed by PBKDF2-HMAC-SHA256 (260,000 iterations) and HMAC-signed logs.
